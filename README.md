# GavidiaStreaming — página pública

Página de catálogo preparada para GitHub Pages, con 90 productos iniciales, imágenes locales, búsqueda, categorías, favoritos y carrito de demostración.

## Publicar la página

En este repositorio, abre **Settings → Pages** y elige **Deploy from a branch**, rama **main**, carpeta **/docs**. Guarda la configuración para que GitHub publique la página.

El contenido público está en `docs/`, con rutas relativas compatibles con una web alojada dentro de `/Superinteligencia.IA/`. No necesita servidor Node.js para mostrar el catálogo.

Los pagos, pedidos y entrega de cuentas no están conectados. El acceso de clientes abre el enlace externo configurado.

El panel de administración y su servidor se incorporarán en el siguiente cambio. GitHub Pages no ejecuta el servidor de administración ni guarda las fotos o los cambios de catálogo.
